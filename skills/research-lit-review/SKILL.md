# 文献综述

## 📖 说明

综述的价值不在「罗列了多少篇」，而在**能不能说清这个领域现在缺什么**。
本 skill 强制走「检索 → 筛选 → 归类 → 找缺口」四步，不允许跳步堆砌。

## 一、检索策略设计（先想清楚再搜）

**别一上来就搜。** 先把检索式写下来：

```
概念 A（主体）  ×  概念 B（方法）  ×  概念 C（场景/指标）
```

以「某类传感器的长期稳定性研究」为例：

| 维度 | 关键词 |
|---|---|
| 主体 | sensor, transducer, sensing element |
| 方法 | calibration, drift compensation, long-term stability |
| 场景 | industrial monitoring, harsh environment |
| 器件 | 该器件类型的标准命名、系列前缀与常用缩写 |

**同义词与缩写都要列进去**——同一概念的多种写法必须都搜。
例如全称与缩写（`long-term stability` / `LTS`）、
连字符与空格写法（`high-temperature` / `high temperature`）。

### 数据库

| 库 | 适合 |
|---|---|
| Web of Science / Scopus | 正式期刊、引文追踪 |
| arXiv | 预印本（更新最快） |
| Google Scholar | 补漏、找引用关系 |
| 学科专门库 | 如物理的 INSPIRE-HEP、医学的 PubMed |

## 二、筛选（三道闸）

1. **标题筛**：明显不相关直接丢
2. **摘要筛**：看它是否真的做了你要找的事
3. **全文筛**：方法是否可信、数据是否够

**记录淘汰理由**——写综述时「为什么没选某类工作」和「选了哪些」同样重要。

**必须记录**：检索日期、检索式、命中数、筛选后数量。
否则综述无法复现。

## 三、归类（不要按时间流水账）

好的归类维度：

- **按技术路线**（如：方法 A 路线 vs 方法 B 路线）
- **按解决的问题**（如：提升精度 / 抑制噪声 / 扩展适用范围）
- **按性能指标**（如：分辨率、转换效率、稳定性）

**用一张对比表把同类工作并排**——这是综述里最有用的一页：

| 工作 | 年份 | 平台 | 关键指标 | 局限 |
|---|---|---|---|---|
| Author A et al. | 2024 | 方案 X | ... | ... |

## 四、找研究缺口（这是综述的落点）

逐条检查：

- **哪些组合没人做过？**（A 方法 + C 场景）
- **哪些指标互相矛盾？**（论文 X 说效率高，论文 Y 说噪声大）
- **哪些假设从没被验证过？**
- **哪些结论只在理想条件下成立？**

缺口要写成**可检验的陈述**，不是「有待进一步研究」这种废话。

## 五、成文结构

```
1. 引言：为什么这个问题重要
2. 技术路线 A：代表工作 + 对比表 + 局限
3. 技术路线 B：同上
4. 横向对比：一张总表
5. 研究缺口：可检验的陈述
6. 我们的切入点：与缺口的对应
```

## 六、诚实性要求

- **引用要能核对**：每篇都要有 DOI 或稳定链接。
  **不确定的引用宁可删掉，也不要编。**
- **不要转引**：能读原文就读原文，别从别人的综述里转引。
- 预印本要标注「preprint, not peer-reviewed」。
- 综述里出现的**数字必须标出处**，同样遵循 A/B/C 三级来源标注
  （实测 / 论文值 / 理论假设）。
- 检索不全面就说明检索范围和局限，**别声称「全面综述」**。

## 七、输出

- 主交付：Markdown 综述草稿 + 对比表
- 附带：**文献清单**（BibTeX），含检索式与检索日期
- 可选：把对比表导出为 xlsx
