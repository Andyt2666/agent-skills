# 公式与数学排版

## 📖 说明

公式排版的两大痛点：**符号前后不一致** 和 **编号引用对不上**。
本 skill 用「先建符号表，再写公式」的顺序把它们从源头掐掉。

## 一、先建符号表（最重要的一步）

**动笔写第一个公式之前，先把符号表列出来。** 这一步省掉后面无数次返工。

| 符号 | 含义 | 单位 | 首次出现 |
|---|---|---|---|
| $\omega_0$ | 特征角频率 | rad/s | 式 (1) |
| $\eta$ | 转换效率 | — | 式 (3) |
| $\Delta t$ | 采样时间窗 | ns | 式 (5) |

**规则：**

- 同一个量**全文只用一个符号**。别一会儿 $\eta$ 一会儿 $\gamma$。
- 矢量/矩阵用粗体或箭头，**全文统一**（别混用）。
- 下标含义要能自洽：$\omega_p$ 的 $p$ 是 pump，全文 $p$ 就都表示 pump。
- 常量与变量区分：常数用正体（$\mathrm{c}$），变量用斜体（$c$）。

## 二、行内 vs 独立

| 场景 | 写法 |
|---|---|
| 句中提一个量 | 行内 `$\eta = 0.8$` |
| 重要公式、需引用 | 独立 `equation` + 编号 |
| 多步推导 | `align` 对齐 |

**判断标准**：这个公式**需要被单独引用吗**？需要就独立编号，
不需要就老老实实放行内。**不要把短式子都拆成独立公式撑篇幅**。

## 三、多行对齐

```latex
\begin{align}
  \eta &= \frac{P_{\mathrm{out}}}{P_{\mathrm{in}}} \label{eq:eff} \\
       &= \frac{N_c}{N_p} \cdot \alpha \label{eq:eff2}
\end{align}
```

- 用 `&=` 对齐等号
- 用 `\label` 打标签，正文用 `\eqref{eq:eff}` 引用
- **`\label` 必须放在公式内部**，放外面会引用错

**编号复用**：多行公式若只想编一个号，用 `equation` + `split`。

## 四、常用结构速查

| 需求 | 命令 |
|---|---|
| 分数 | `\frac{a}{b}`；文本里的分数用 `a/b` |
| 绝对值 / 范数 | `\lvert x \rvert` / `\lVert x \rVert` |
| 期望 / 方差 | `\mathbb{E}[X]` / `\operatorname{Var}(X)` |
| 单位 | `\mathrm{nm}` 或 `siunitx` 的 `\SI{1550}{nm}` |
| 量纲正确的数 | `\SI{1.5e-3}{W}`（推荐 siunitx） |
| 微分 | `\mathrm{d}x`（正体 d，物理惯例） |
| 虚数单位 | `\mathrm{i}`（物理）或 `i`（数学，看期刊） |

**物理类期刊惯例**：自然常数用正体，微分算子 d 用正体，
虚数单位用正体 i。数学类期刊相反。**按目标期刊来**。

## 五、单位与量纲

- **数字与单位之间要有空格**：`1550 nm`，不是 `1550nm`
- **单位用正体**，不能用斜体（斜体单位是错误写法）
- **量纲要能对上**：写完公式做一次量纲检查，
  左边是 [W]，右边也得是 [W]
- 百分号与度数：`80\%`、`30^\circ`
- 数值范围：`1550--1560 nm`（双连字符，不是单连字符）

## 六、跨平台落地

| 目标 | 做法 |
|---|---|
| LaTeX 论文 | 直接用，注意 `siunitx` / `amsmath` 宏包 |
| Word | 用 Word 内置公式编辑器或 MathType；**别贴图片**（不可编辑、字号会错） |
| Markdown | `$...$` 行内，`$$...$$` 独立；渲染器需支持 KaTeX/MathJax |
| HTML 报告 | MathJax / KaTeX；注意离线环境需本地化 |
| 代码注释 | 用 Unicode 或纯 ASCII 近似，别指望渲染 |

**Word 里最忌讳把公式截图贴进去**——一改字号就糊，审稿人也没法编辑。

## 七、质检清单

- [ ] 符号表与正文公式**一一对应**，没有孤儿符号
- [ ] 所有编号公式**都被正文引用过**（没被引用的公式考虑删掉）
- [ ] `\label` / `\eqref` 全部解析成功（编译无 `??`）
- [ ] 单位正体、数字与单位有空格
- [ ] 量纲自洽
- [ ] 同一量全文符号统一

## 八、诚实性要求

- **推导不许跳步掩盖问题**。中间某步不严谨，就标注出来，
  不要用「显然可得」糊过去。
- **近似必须声明**：做了小角近似 / 弱耦合近似 / 忽略高阶项，
  要写明近似条件和适用范围。
- **公式里出现的参数同样要标来源级别**（实测 / 论文值 / 理论假设），
  尤其是从别处引用的经验公式。
- 量纲对不上时**不要硬凑系数**——那通常意味着模型错了。

## 九、输出

- 主交付：LaTeX 片段（可编译）
- 附带：**符号表**（Markdown 表格）+ 推导步骤说明
- Word 场景：可编辑的公式对象，不贴图
